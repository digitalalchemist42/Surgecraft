# Surgecraft
A quick attempt at a free Starcraft TMG Roster Maker

## Using it
The site is served with GitHub Pages. You can install it as an app: in Chrome, use **Install app**; on an iPhone in Safari, use **Share → Add to Home Screen**. It works offline after the first visit.

Rosters are saved in each device's browser storage and are never stored in this repository. To move a roster between devices, use the app's Export tab or share code.

Unit and card data and artwork are from the official unit cards, for personal, non-commercial use.
